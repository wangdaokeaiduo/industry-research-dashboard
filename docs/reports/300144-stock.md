## 3. 行业景气度

- 景气等级：文旅需求有韧性，公司经营分化且盈利承压
- 变化方向：旺季客流与新项目向上 / 存量景区利润恢复偏慢
- 景气评分：58/100
- 判断：旅游总客流不等于宋城利润。公司不同景区表现分化，杭州较稳、上海和西安增长，张家界、广东、丽江、三亚承压；现金流健康，但收入和利润仍在下降。

## 4. 供需关系

- 供需状态：旅游需求稳定但演艺供给竞争加剧，项目和区域高度分化
- 变化方向：旺季改善、盈利传导待确认
- 综合判断：居民短途与休闲旅游需求仍在，但主题乐园、地方演艺、沉浸式项目和线上内容共同争夺游客时间。宋城依靠IP和演艺密度获取流量，真正稀缺的是可持续上座率、客单价和跨区域复制效率。
