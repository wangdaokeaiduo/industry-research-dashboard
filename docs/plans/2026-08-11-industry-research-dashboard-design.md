# 行业研究动态展示站设计

## 目标

构建一个本地运行的投研报告网站。外部软件把行业研究 JSON 写入 `data/reports/` 后，本地服务自动发现并通过服务器事件推送给网页；网页无需刷新即可展示最新版报告。网站不调用 AI，也不需要 API Key。

## 架构

使用 React + Vite 构建界面，Node HTTP 服务负责静态文件、报告读取、Schema 校验和 SSE 实时通知。报告文件采用稳定的 JSON 结构，允许模块缺失；损坏文件不会覆盖已加载报告，并通过错误状态提示。开发模式由一个 Node 启动器同时提供 Vite 与数据 API，生产模式由同一服务托管构建产物。

## 信息架构

左侧是可搜索、可按周期类型筛选的报告导航。顶部显示行业、报告期、更新时间和实时同步状态。主视图依次包含一页结论、周期阶段轨道、反转条件矩阵、真实数据指标、产业链、技术分析、基本面—技术面共振、情景与风险。桌面端采用专业投研终端布局，移动端转为顶部选择器和纵向信息流。

## 数据流与异常

服务启动时扫描报告目录，按更新时间排序。文件创建或修改后重新解析，校验成功才更新内存快照并发送 `reports-updated` 事件。前端收到事件后重新获取列表，并保留当前报告；若当前报告更新则无闪烁替换。Schema 错误显示文件名和错误摘要，连接中断时前端自动重连并显示离线状态。

## 验证

验证构建、API 列表与详情、写入新文件后的自动通知、无效 JSON 隔离、搜索筛选、报告切换，以及桌面和移动布局。视觉实现以确认后的概念稿为基准，通过浏览器截图与概念稿对照。
