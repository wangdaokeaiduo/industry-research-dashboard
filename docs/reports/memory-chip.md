## 3. 行业景气度

- 景气等级：高景气
- 变化方向：价格加速、AI高端结构性紧缺
- 景气评分：88/100
- 判断：存储行业已从周期复苏进入价格与盈利扩张阶段。HBM、服务器DRAM和企业级SSD需求最强，产能向高端迁移进一步挤压通用DRAM和NAND供给；消费端仍有成本挤压，行业并非所有终端同步繁荣。

## 4. 供需关系

- 供需状态：高端紧缺、通用产品涨价扩散
- 变化方向：供不应求
- 综合判断：AI服务器增加带宽和容量需求，HBM更高的晶圆消耗与产能迁移挤压普通DRAM，NAND产能也向企业SSD倾斜。需求增长目前快于有效供给，但PC手机客户承受成本压力，需警惕涨价对终端需求的反噬。

- 证伪条件：价格环比转跌、原厂库存快速回升、AI客户削减订单或新增产能提前释放。

- 证据等级：全文/摘要级归纳 · 高置信度（两家全球原厂与独立价格机构相互印证；A股映射需单独下调置信度。）

**共性**

- **AI正在提高存储带宽和容量需求**：HBM、服务器DRAM和企业SSD订单均强。（Micron + Samsung + TrendForce）
- **有效供给短期受限**：洁净室、建设周期、HBM晶圆消耗与产能迁移共同限制位元增长。（Micron + TrendForce）

**不同点**

- **景气扩散与持续时间**：原厂判断供需紧张延续至2026年后；行业价格报告同时提示PC手机终端承压。；投资含义：可参与盈利扩张，但必须设置价格转跌和库存回升的周期失效条件。

**整合后的新判断：** 存储处于扩张阶段而非左侧底部；产业价值高，但交易需防涨价预期过度和A股映射偏差。

**验证方法：** 每月核对合约价、原厂库存与资本开支；中报核对A股毛利率、库存和现金流；每周核对板块量价。
